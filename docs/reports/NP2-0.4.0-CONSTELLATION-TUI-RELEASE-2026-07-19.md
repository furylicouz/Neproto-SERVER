# NP/2 0.4.0 Constellation Console Release Evidence

## Executive summary

The line-oriented `np` dashboard has been replaced for interactive terminals
with a native, full-screen Constellation operations console. The console is an
independent Go/tcell implementation inspired by the multi-panel science-fiction
layout of eDEX-UI; it does not copy eDEX-UI source code or bundled assets.

The production VPS was updated atomically by replacing only `neprotoctl`.
`neproto-server` and Caddy were not restarted, so the VPN data plane remained
online during the console update.

## Interface delivered

| Surface | Live information or action |
|---|---|
| Header | Clock, NP/2 version, F1-F8 shortcuts |
| System monitor | Host, uptime, load, memory bar, RX/TX totals and live rates |
| Control terminal | HTTPS/WSS, HTTP/3 and WebRTC state plus real management actions |
| Network status | Public domain/IP, service state, users, backups and network globe |
| Secure filesystem | Config, users, certificates, backups and sanitized events |
| Compact mode | Usable action list and resize guidance below 100x30 |

Keyboard controls are arrows or `j`/`k`, `Enter`, `F1`-`F8`, `r`, and `q`.
The recovery interface remains available with `NEPROTO_CLASSIC_UI=1 np`.

counter. This removes a test-only timing race without weakening the assertion.

## Security boundaries

- The console displays public node identity and aggregate counters only.
- Credentials, secret routes, certificate contents, target destinations, and
  user traffic are not rendered.
- Mutating operations still use the existing confirmation and validation
  paths; the TUI does not bypass manager policy.
- Recent events use the existing sanitized service log surface.

## Deployment and rollback

Live target: `104.171.136.10`, version `np2-0.4.0`.

The previous management binary is retained at:

```text
/var/backups/neproto/releases/pre-np2-0.4.0-tui-20260719T001853Z/neprotoctl
```

Rollback is an atomic replacement of `/usr/local/bin/neprotoctl` with that
binary. It does not require a VPN service restart.
