## 📌 Executive Summary

NP/2 v2.2 now has complete local implementations for authenticated extension
negotiation, reliable UDP, carrier datagrams, HTTP/3/WebTransport,
dual-channel WebRTC, HTTPS fallback, authenticated carrier racing, iOS
reconnect/switch/drain migration, desktop SOCKS5 UDP, observability, server
management, v2 QR onboarding, and global/per-user abuse controls.

All available local Windows, Linux race, macOS Go, Swift, framework, unsigned
iphoneos, fuzz, vulnerability, deterministic packaging, and isolated installer
gates passed. The real VPS canary now passes authenticated HTTP/3, WebRTC,
HTTPS, and UDP-blocked HTTPS fallback. Overall production approval remains
blocked on the physical-iPhone and capacity gates described below.

## Security and abuse controls

- Global pre-authenticated session ceiling plus authenticated per-user session
  ceiling.
- Per-session, process-wide, and per-user TCP/UDP concurrency ceilings.
- Atomic global and per-user UDP packet, byte, port-53 DNS, and target-creation
  token buckets.
- Bounded 1,024 logical UDP targets per association.
- First-reply UDP anti-amplification: at most `3 * client_bytes + 1280` before
  the target is marked as replied.
- Destination-free and credential-free Prometheus counters for all rejection
  classes.
- Strict recursive duplicate-key rejection and bounded config parsing.

## ✅ Recommendations

1. Keep the overall release at `RC` until the physical-device and capacity
   gates pass; the server canary itself is approved.
2. Monitor service restarts, resource-limit counters, and carrier selection on
   the live VPS while retaining the verified pre-0.3.0 rollback backup.
3. Run the signed iPhone matrix: connect/disconnect, DNS, TCP, UDP, screen lock,
   background, Wi-Fi to LTE, LTE to Wi-Fi, and loss/recovery.
