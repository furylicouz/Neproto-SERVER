# NP/2 v2.2 Production Implementation Plan

Status: approved and in progress since 2026-07-18

Date: 2026-07-18

## Delivery rule

Every slice is independently testable, keeps the deployed v2.1 TCP path
working, and has a rollback. A slice is not complete because it compiles; its
unit/integration tests, resource cleanup checks, metrics, documentation, and
relevant physical-device validation must pass.

## TDD sequence per slice

1. Add one failing contract or regression test.
2. Implement the smallest production behavior that satisfies that contract.
3. Add boundary, malformed-input, cancellation, and resource-limit tests.
4. Run the focused package tests and race-sensitive tests.
5. Run `go test ./...` and `go vet ./...`.
6. For mobile or carrier work, build and run on the physical iPhone and collect
   sanitized client/server evidence.
7. Update protocol/operations documentation and the rollback note.

## Release evidence

The final release report must contain exact commands, build identifiers,
server/client versions, test dates, environment, raw benchmark artifacts, and
known limitations. A green local unit suite alone is not sufficient evidence
for production completion.
